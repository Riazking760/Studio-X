# Studio X - Telegram Mini App

100% Free All-in-One Digital Photo Studio & Multi-Print Web App built for Telegram Mini Apps (TMA).

## Features
- **AI Background Remover:** 1-click client-side background removal (no paid API required).
- **Solid Background Colors:** Instant White, Green, Blue, and Sky Blue studio backgrounds.
- **Custom & Preset Resize:** Passport (35x45mm), Stamp (20x25mm), Square (40x40mm), or custom millimeter sizing.
- **Photo Adjustments:** Real-time Brightness and Contrast sliders.
- **Multi-Copy Direct Print:** Auto-arranged grid with dashed cutting borders via browser print (`window.print()`).

## Quick Deploy (GitHub + Vercel)
1. Upload `index.html` and `vercel.json` to a GitHub repository.
2. Import the repository into Vercel and click **Deploy**.
3. Copy your Vercel HTTPS URL and set it as your Web App URL in `@BotFather`.
